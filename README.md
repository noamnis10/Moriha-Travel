# Moriah Travel — Landing Page

אתר נחיתה סטטי (HTML/CSS/JS) לסוכנות הנסיעות Moriah Travel.

## הרצה מקומית

אין תהליך build — פשוט פתחו את `index.html` בדפדפן, או הריצו שרת סטטי פשוט:

```bash
python3 -m http.server 8000
```

ואז גשו ל-`http://localhost:8000`.

## מבנה הפרויקט

```
index.html        # כל דפי האתר (עמוד יחיד עם עוגנים)
css/styles.css     # כל העיצוב
js/main.js         # תפריט נייד, לינקים לוואטסאפ, אקורדיון שאלות נפוצות, אנימציות גלילה
assets/logo.svg    # הלוגו המלא (אייקון + טקסט)
assets/logo-icon.svg # האייקון בלבד (משמש גם כ-favicon)
```

## תוכן שדורש עדכון לפני עלייה לאוויר

- **המלצות לקוחות** (`#testimonials`) — כרגע טקסט לדוגמה. יש להחליף בהמלצות אמיתיות עם רשות הלקוחות.
- **שאלות נפוצות** (`#faq`) — שאלות טיפוסיות לסוכנות נסיעות. כדאי לעדכן לפי המדיניות בפועל (ביטולים, תשלומים וכו').
- **חבילות/יעדים** (`#packages`) — מכילות כרגע רק את שתי החבילות שסופקו (בטומי, לימסול). ניתן להוסיף כרטיסים נוספים על ידי שכפול מבנה `<article class="package-card">`.
- **פרטי קשר** — מוצג רק מספר הוואטסאפ. אם יתווספו אימייל, כתובת פיזית או רשתות חברתיות, יש להוסיף אותם ל-footer ולסקשן "צור קשר".

## וואטסאפ

כל כפתורי הוואטסאפ באתר בנויים אוטומטית ב-`js/main.js` מתוך `data-wa-text` על האלמנט, אל המספר
`972508863586`. לשינוי המספר, יש לערוך את המשתנה `WHATSAPP_PHONE` בראש הקובץ.
