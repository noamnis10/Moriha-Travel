# Moriah Travel — Landing Page

אתר נחיתה לסוכנות הנסיעות Moriah Travel. בנוי עם React + Vite + Tailwind CSS.

## הרצה מקומית

```bash
npm install
npm run dev
```

ואז גשו לכתובת שמודפסת בטרמינל (בד"כ `http://localhost:5173`).

## Build לפרודקשן

```bash
npm run build
```

התוצר יופיע בתיקיית `dist/` — ניתן להעלות אותו כמו שהוא לכל אחסון סטטי (Netlify, Vercel, GitHub Pages וכו').

## מבנה הפרויקט

```
src/
  components/     # Navbar, Hero, About, Services, Pricing, Testimonials, Faq, ContactForm, Footer, WhatsAppFab
  pages/
    Home.jsx      # עמוד הנחיתה הראשי
    Dashboard.jsx # מסך ניהול חבילות (ראו הערה למטה)
  lib/
    packages.js   # נתוני החבילות + שמירה/טעינה מ-localStorage
    whatsapp.js   # בניית לינקים לוואטסאפ
  hooks/
    useReveal.js  # אנימציית הופעה בגלילה
```

## צבעי המותג

הפלטה מבוססת על תמונת ההשראה ששימשה לעיצוב (גוני טורקיז-אוקיינוס כהים, לבן ושחור), ולא על צבעי הלוגו המקורי. הטוקנים מוגדרים ב-`src/index.css` תחת `@theme` (Tailwind v4): `teal-950..50`, `ink`, `paper`, `gold`. הלוגו עצמו (`src/assets/logo.svg`) נשאר בצבעיו המקוריים כפי שסופק.

## מסך ניהול חבילות (`/dashboard`)

מסך נפרד שמאפשר להוסיף, לערוך ולמחוק חבילות/דילים בלי לגעת בקוד.

**חשוב להבין:** מכיוון שזהו אתר סטטי ללא שרת/מסד נתונים, השינויים שנעשים במסך הזה **נשמרים רק בדפדפן שבו נעשו** (ב-localStorage). כלומר:
- מצוין ככלי לתצוגה מקדימה מקומית או לעדכון תוכן שאתם מזינים ידנית לקוד לאחר מכן.
- **לא** מתאים כפי שהוא כדי שכל הגולשים באתר החי יראו חבילות חדשות שהוספתם - לכך נדרש חיבור אמיתי לשרת/מסד נתונים (למשל Supabase, Firebase, או שירות דומה). זה תוספת אפשרית להמשך אם תרצו שהדשבורד יעדכן את האתר בפועל עבור כולם.

חבילות ברירת המחדל (אם לא בוצע שינוי) מוגדרות ב-`src/lib/packages.js`.

## וואטסאפ

כל כפתורי הוואטסאפ באתר משתמשים בפונקציית `waLink()` מתוך `src/lib/whatsapp.js`, שבונה לינק ל-`wa.me` עם הודעה מוכנה מראש. לשינוי המספר, יש לערוך את `WHATSAPP_PHONE` בקובץ הזה.

## תוכן שדורש עדכון לפני עלייה לאוויר

- **המלצות לקוחות** (`src/components/Testimonials.jsx`) — כרגע טקסט לדוגמה, יש להחליף בהמלצות אמיתיות עם רשות הלקוחות.
- **שאלות נפוצות** (`src/components/Faq.jsx`) — שאלות טיפוסיות לסוכנות נסיעות, כדאי לעדכן לפי המדיניות בפועל.
- **חבילות/יעדים** — ניתן לעדכן ידנית ב-`src/lib/packages.js`, או דרך מסך הניהול (ראו הערה למעלה לגבי המגבלה).
