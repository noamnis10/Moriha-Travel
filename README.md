# Moriah Travel — Landing Page

אתר נחיתה לסוכנות הנסיעות Moriah Travel. בנוי עם React + Vite + Tailwind CSS.

## הרצה מקומית

```bash
npm install
npm run dev
```

ואז גשו לכתובת שמודפסת בטרמינל (בד"כ `http://localhost:5173`).

## Build לפרודקשן

```bash
npm run build
```

התוצר יופיע בתיקיית `dist/` — ניתן להעלות אותו כמו שהוא לכל אחסון סטטי (Netlify, Vercel, GitHub Pages וכו').

## מבנה הפרויקט

```
src/
  components/     # Navbar, Hero, About, Services, Pricing, Testimonials, Faq, ContactForm, Footer, WhatsAppFab
    ui/           # button.jsx, separator.jsx - shadcn-style primitives (מבוססים על רכיבי 21st.dev אמיתיים)
    PackageSearch.jsx # שורת החיפוש בהירו - מבוסס על רכיב "Flight Search" מ-21st.dev
  pages/
    Home.jsx      # עמוד הנחיתה הראשי
    Dashboard.jsx # מסך ניהול חבילות (ראו הערה למטה)
  context/
    PackageSearchContext.jsx # מעביר את החיפוש מההירו לסינון בפועל בסקשן החבילות
  lib/
    packages.js   # נתוני החבילות + שמירה/טעינה מ-localStorage
    whatsapp.js   # בניית לינקים לוואטסאפ
    utils.js      # cn() - עזר למיזוג classNames (shadcn convention)
  hooks/
    useReveal.js  # אנימציית הופעה בגלילה
```

## צבעי המותג

הפלטה מבוססת על תמונת ההשראה ששימשה לעיצוב (גוני טורקיז-אוקיינוס כהים, לבן ושחור), ולא על צבעי הלוגו המקורי. הטוקנים מוגדרים ב-`src/index.css` תחת `@theme` (Tailwind v4): `teal-950..50`, `ink`, `paper`, `gold`. הלוגו עצמו (`src/assets/logo.svg`) נשאר בצבעיו המקוריים כפי שסופק.

## מסך ניהול חבילות (`/dashboard`)

מסך נפרד שמאפשר להוסיף, לערוך ולמחוק חבילות/דילים בלי לגעת בקוד.

**חשוב להבין:** מכיוון שזהו אתר סטטי ללא שרת/מסד נתונים, השינויים שנעשים במסך הזה **נשמרים רק בדפדפן שבו נעשו** (ב-localStorage). כלומר:
- מצוין ככלי לתצוגה מקדימה מקומית או לעדכון תוכן שאתם מזינים ידנית לקוד לאחר מכן.
- **לא** מתאים כפי שהוא כדי שכל הגולשים באתר החי יראו חבילות חדשות שהוספתם - לכך נדרש חיבור אמיתי לשרת/מסד נתונים (למשל Supabase, Firebase, או שירות דומה). זה תוספת אפשרית להמשך אם תרצו שהדשבורד יעדכן את האתר בפועל עבור כולם.

חבילות ברירת המחדל (אם לא בוצע שינוי) מוגדרות ב-`src/lib/packages.js`.

## וואטסאפ

כל כפתורי הוואטסאפ באתר משתמשים בפונקציית `waLink()` מתוך `src/lib/whatsapp.js`, שבונה לינק ל-`wa.me` עם הודעה מוכנה מראש. לשינוי המספר, יש לערוך את `WHATSAPP_PHONE` בקובץ הזה.

## תוכן שדורש עדכון לפני עלייה לאוויר

- **המלצות לקוחות** (`src/components/Testimonials.jsx`) — כרגע טקסט לדוגמה, יש להחליף בהמלצות אמיתיות עם רשות הלקוחות.
- **שאלות נפוצות** (`src/components/Faq.jsx`) — שאלות טיפוסיות לסוכנות נסיעות, כדאי לעדכן לפי המדיניות בפועל.
- **חבילות/יעדים** — ניתן לעדכן ידנית ב-`src/lib/packages.js`, או דרך מסך הניהול (ראו הערה למעלה לגבי המגבלה).

## רכיבי 21st.dev

שני רכיבים באתר נמשכו בפועל מהקטלוג של 21st.dev (חשבון free, 2 משיכות ליום) והותאמו לעיצוב ולתוכן של האתר:

- **שורת החיפוש בהירו** (`src/components/PackageSearch.jsx`) — מבוסס על הרכיב "Flight Search", מותאם לחיפוש יעד/תאריכים/נוסעים. החיפוש אמיתי: הוא מסנן בפועל את רשימת החבילות בסקשן "יעדים וחבילות" לפי היעד שהוזן (כולל מסך "לא נמצאה חבילה" עם הצעה לבקש הצעת מחיר בוואטסאפ).
- **כרטיסי החבילות** (`src/components/Pricing.jsx`) — מבוססים על הרכיב "Pricing table" (כרטיסי מחיר עם רשימת פיצ'רים מסומנת ב-✓, תג "מומלץ" לחבילה המשתלמת ביותר), מותאמים לתוכן טיולים במקום תוכניות מנוי.

שאר הרכיבים באתר (Navbar, Hero, About, Services, Testimonials, Faq, ContactForm, Footer, ומסך ה-Dashboard) נבנו ידנית בהשראת דפוסי עיצוב דומים - ניתן למשוך רכיבים אמיתיים גם עבורם בסשן עתידי, בכפוף למגבלת 2 המשיכות ליום של החשבון החינמי.

## תמונות רקע (Higgsfield / Higgs MCP)

לפי בקשה מפורשת, נוצרו נכסים חזותיים דרך Higgsfield ומוגדרים ב-`src/lib/media.js`:

- **תמונת "אודות"** - רגע פגישת ייעוץ אישית וחמה, תואם את מסר "לא חבילה מוכנה - מסלול שנבנה סביבכם".
- **שתי תמונות ליעדי בטומי ולימסול** - רגעים אנושיים (זוג) ביעד, במקום גרפיקה גנרית של נוף.

כל התמונות עוברות שכבת גוון טורקיז (`mix-blend-luminosity` + גרדיאנט) כדי להתאחד עם צבעי המותג במקום להיראות כתוספת זרה.

**רקע ההירו הוחלף מסרטון AI לתמונה אמיתית שסיפק הלקוח** (נוף סנטוריני בשקיעה) - הקוד ב-`src/components/Hero.jsx` מצפה לקובץ בנתיב:

```
public/media/hero-santorini.jpg
```

יש להעלות את הקובץ בדיוק לנתיב ולשם הזה (למשל דרך ממשק ה-Web של GitHub: Add file → Upload files, בתוך תיקיית `public/media/`). ברגע שהקובץ קיים בריפו, הוא יופיע אוטומטית ברקע ההירו - אין צורך בשינוי קוד נוסף.

**הערה חשובה על אחסון:** בגלל מדיניות הרשת של סביבת הפיתוח הזו, לא הצלחתי להוריד את קבצי המדיה בפועל ולשמור אותם בריפו - הם מוגשים ישירות מ-CDN של Higgsfield (קישורים ב-`src/lib/media.js`). זה עובד מצוין לגלישה רגילה, אבל לאורך זמן עדיף לא להיות תלויים בשירות חיצוני: מומלץ להוריד את הקבצים בעצמכם (הקישורים ב-`media.js`) ולשמור אותם תחת `public/media/`, ואז לעדכן את הנתיבים באותו קובץ לנתיבים מקומיים (`/media/hero.mp4` וכו').

**הערה על תקציב קרדיטים:** נוצלו כ-40 קרדיטים בלבד (מתוך 325 בחשבון) - תמונה בודדת עולה כ-1-2 קרדיטים, והסרטון היחיד שנוצר עלה כ-32.5 קרדיטים.
